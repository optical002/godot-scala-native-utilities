# Changelog — `rx`

Versions are plain-semver git tags of the
[godot-scala-native-utilities](https://jitpack.io/#optical002/godot-scala-native-utilities)
repo, built by JitPack under the group
`com.github.optical002.godot-scala-native-utilities` (all modules share one
tag). The topmost *Unreleased* section is the current dev version (what
`sbt publishLocal` produces); it appears on JitPack only once its tag is
pushed.

## [0.1.2] — 2026-07-12

- No functional changes; version moves in lockstep with the other modules.

## [0.1.1] — 2026-07-06

First JitPack release (group moved from `io.github.optical002` to
`com.github.optical002.godot-scala-native-utilities`).

Reactive cells: `RxRef`/`RxVal`/`RxObservable`/`RxSubject`, `Tracker`-scoped subscriptions, cats-core based combinators.
